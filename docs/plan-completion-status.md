## 计数之外的验证边界

- qmake 本轮只配置成功并核对新增源码注册；主要完整构建路径是两平台 CMake。
- Windows 安装程序仍未签名；安装/启动烟测不等于 SmartScreen 信任验证。
- OpenSSL provider 的实际操作有回归，但没有独立第三方密码学审计。
- GUI 是列明场景的自动验收，不是所有系统通知策略、主题/DPI、多屏和托盘/
  头像组合的人工认证；成员菜单信号分发不能证明每项服务端持久化变更。

这些事实保留在交付说明中。签名证书和第三方审计不是三份原计划的强制交付项，
没有为它们新增阻塞任务。
