# QQNT UI 修复计划（rit-v2）—— 后端能力就绪，补齐 UI 接入

## 摘要

`tauri-qqnt` 前端与当前 Qt 后端共用同一套 C++ 引擎/协议：36 条 QQNT 命令已在 `qqnt_engine_command_router.cpp` 路由，登录/聊天/群/文件/E2E/设置等后端能力已就绪。当前计划聚焦**把 UI 与 Tauri 壳层能力对齐**，从主界面、聊天面板一路到截图、本地消息操作、文件/图片工具、桌面壳层命令，全部接入后端。

## 已确认的后端能力（当前 Qt 项目已有）

- 登录/注册/注销/连接/断开
- 在线用户、好友搜索/申请/同意
- 私聊、群聊、建群、群公告、成员权限
- 群精华、消息收藏、撤回、禁言、成员资料
- 文件/图片发送、取消、断点续传
- E2E 状态、身份发布/信任、会话轮换
- 资料更新、设置同步

对应路由：`src/qqnt_engine_command_router.cpp`。`src/qqnt_backend_service.cpp` 已提供本地消息操作（删除、收藏、表情、置顶、多选、引用、精华、撤回、转发、查看资料、举报、拉黑、设置群昵称、操作记录读取）以及图片 Base64、文件保存等工具。

## 尚未对齐的 UI 层

### 1. 主界面骨架与导航
- 标题栏：需移除搜索框，增加昵称、最大化/最小化/关闭按钮，支持拖拽。
- AppNav：选中态改为 `bg-primary-soft` + `text-primary`，mock 项加黄色小点，未读角标红色。
- MainWindow：无边框 + `TitleBar + AppNav + QStackedWidget` 布局，尺寸 1100x740 / 最小 860x540。

### 2. 消息页布局
- 左侧 `SessionList`（260px，头像/名称/时间/最后消息/未读/置顶），右侧 `ChatPanel`（标题/消息列表/Composer）。
- 当前左侧仍是树形联系人列表，需重构。

### 3. 聊天面板细节
- 消息气泡：自己主色蓝底白字，对方 `bg-tertiary` 深字，36px 头像，引用/转发标签，系统消息居中。
- 文件/图片：图片缩略圆角、文件卡片、下载/打开文件夹。
- Composer：工具栏图标、表情选择面板（10 分类）、@ 补全、占位文案、快捷键、发送按钮、禁言提示。
- 右键菜单：消息菜单（复制/转发/收藏/多选/引用/精华/撤回/删除），头像菜单（发消息/@/资料/好友/群昵称/禁言/管理员/屏蔽/举报）。

### 4. 本地消息与操作接入（QQNTBackendService）
- 将上述右键菜单动作统一调用 `QQNTBackendService` 的本地命令，而不是直接操作数据库/内存。
- 本地操作记录读取与回显。
- 收藏、表情、置顶备注状态同步到 UI。

### 5. 文件与图片本地工具
- 统一入口：另存为、Base64 预览、保存到下载目录。
- 接入已有 `QQNTBackendService` 的图片读取和文件保存命令。

### 6. 截图能力（Windows 平台）
- 新分支已在做全屏选择覆盖层。
- 剩余：虚拟桌面跨显示器截图、窗口排除自身截图、截图缓存释放/裁剪。
- 隐藏/恢复主窗口在截图前后已部分实现，需对齐调用链。

### 7. 桌面壳层命令
- `hide_main_window` / `restore_main_window`：Qt 直接调用，无需 Rust invoke。
- 共享缓冲区：Qt Widgets 用 `QPixmap` 内存对象替代，不再走共享内存。
- 主屏/虚拟桌面信息：Qt 用 `QScreen`/`QGuiApplication::screens()` 获取。

### 8. 主题与通用样式
- 统一 `ThemeManager` 和 `style-qqnt.qss`（亮/暗色）。
- 字体、圆角、滚动条、边框、按钮、输入框、列表项 hover。
