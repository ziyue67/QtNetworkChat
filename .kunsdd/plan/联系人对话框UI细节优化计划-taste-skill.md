# 联系人对话框 UI 细节优化计划（taste-skill + Qt UI）

## 目标

在不改变现有联系人、好友分组和建群后端合同的前提下，对照
`D:\C++VS pro\tauri-qqnt\src\components\contact`，优化以下 Qt Widgets 界面：

- `ContactsView` 左侧搜索区与加号菜单
- `AddFriendDialog`
- `FriendManagerDialog`
- `CreateGroupDialog`

本轮属于现有产品界面的定向精修，不重建视觉语言。保持 QQNT 的安静、紧凑、工作型界面，使用现有 `ThemeManager` 与 `DialogStyle` 令牌。

## 设计读法

- 产品类型：Windows 桌面即时通信工具。
- 视觉语言：QQNT 风格、克制、轻量、清晰，不做营销页式夸张层级。
- 参数：`DESIGN_VARIANCE=3`、`MOTION_INTENSITY=2`、`VISUAL_DENSITY=6`。
- 主强调色仅使用 `ThemeManager::primaryColor()`；头像预设色只表示头像内容，不作为界面强调色。
- 控件圆角维持 4-8px；头像和圆形勾选除外。

## 步骤 2：统一视觉令牌与基础控件

- [ ] 将对话框内零散字体、边距、圆角、行高整理为局部常量或 `DialogStyle` 角色规则。
- [ ] 字号控制在 3-4 档：页面标题、正文/控件、辅助文本、紧凑标签。
- [ ] 统一输入框高度、主/次按钮高度、焦点描边、disabled、pressed 与 hover 状态。
- [ ] 使用系统字体和 point size，检查 125%/150% DPI 及 Windows 大字体。
- [ ] 清理以空格排版的文本，例如“按分类创建 ... 更多 >”，改为真实布局和独立控件。
- [ ] 关闭、返回、搜索、添加等工具按钮使用项目已有图标资源或 Qt 标准图标；统一 16px 视觉尺寸和 tooltip。

## 步骤 4：AddFriendDialog 精修

- [ ] 搜索按钮补搜索图标、loading 反馈和禁用态，避免按钮文字宽度变化导致布局跳动。

## 步骤 5：FriendManagerDialog 精修

- [ ] 验证浅色/深色主题下 X 按钮、危险色和 disabled 对比度。

## 步骤 6：CreateGroupDialog 视觉与交互精修

### 选择页

- [ ] 使用真实布局表达“按分类创建 / 更多 / chevron”，移除空格对齐。
- [ ] 最近聊天和我的好友放在同一滚动区，分区标题、空状态与成员行节奏对齐参考。
- [ ] 成员行使用 16px 圆形勾选、32px 头像、备注优先昵称，整行可点击。
- [ ] 已选成员改为真正可换行的横向 chip 流布局，包含 22px 头像、昵称和关闭图标。
- [ ] 右侧“创建群聊”标题、X、确定/取消顺序和页脚高度与参考一致。

### 分类页

- [ ] 分类卡只用于分区容器，减少边框；保持 4 列稳定网格和 9px 左右间距。
- [ ] 分类项加入统一图标和语义色；可展开项显示 chevron 旋转状态。
- [ ] 子分类展开保持当前分区内的空间关系，避免其它分区无意义跳动。
- [ ] 处理 600x540 范围内滚动条、长分类名和 150% DPI 文本。

### 信息页

- [ ] 名称输入、头像选择、分类选择形成三个清晰层级，不把整个页面堆成嵌套卡片。
- [ ] 随机头像和 6 个头像实现各自颜色、选中 ring、角标和键盘状态。
- [ ] 快捷分类支持选中态，并提供可点击的“重新选择”入口。
- [ ] 服务声明使用圆形勾选 + 可换行文字，默认同意状态与参考一致。
- [ ] “立即创建”禁用条件、pressed、loading、错误反馈保持页面尺寸稳定。
- [ ] 页面前进/返回采用 150-220ms 的轻量透明度反馈；尊重减少动画设置，Qt Widgets 不做大范围几何动画。

## 步骤 7：可访问性和边界状态

- [ ] 所有交互控件有 tooltip/accessibilityName，图标按钮不依赖图形猜用途。
- [ ] Tab 顺序符合从左到右、从上到下；焦点框在明暗主题均清楚。
- [ ] Esc 关闭，Enter 触发当前主操作，Space 切换勾选；无键盘陷阱。
- [ ] 检查空好友、无最近会话、超长昵称、32 字群名、长分组名和大量已选成员。
- [ ] 对比度：正文至少 4.5:1，边框/焦点/控件状态至少 3:1；颜色不是唯一状态信号。
- [ ] 检查 100%/125%/150% DPI 和浅色/深色主题。

## 验收标准

1. 四个目标界面与 `tauri-qqnt` 的信息层级、空间关系和状态表达一致。
2. 没有以空格、硬编码坐标或字体字符代替正式布局/图标的关键控件。
3. 明暗主题、125%/150% DPI、键盘导航和长文本下无重叠、裁切或跳动。
4. 创建群聊两条路径、好友分组和加好友状态保持现有功能与持久化行为。
5. 构建和相关测试通过，并有真实运行截图作为视觉完成证据。
